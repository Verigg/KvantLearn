# KvantLearn — Платформа учебных материалов ДТ «Кванториум»

**KvantLearn** — каталог структурированных обучающих материалов, модулей и практических уроков по IT, программированию и современным технологиям для кванторианцев и наставников.

---

## 🚀 Технологический стек
- **Python**: 3.13 / 3.11+
- **Фреймворк**: Django 5.x
- **База данных**: SQLite (по умолчанию) с поддержкой переключения на PostgreSQL через `DATABASE_URL`
- **Шаблоны**: Django Templates (`.html`)
- **Стилизация**: Tailwind CSS (через CDN в `base.html`, без сборки Node.js)
- **Иконки**: Lucide Icons (через CDN `<i data-lucide="..."></i>`)
- **Рендеринг контента**: библиотека `markdown` с расширениями `fenced_code` и `tables`, видеоплеер YouTube / VK / MP4

## 🛠️ Установка и запуск

### 1. Клонирование и создание виртуального окружения
```bash
python3 -m venv venv
source venv/bin/activate  # На Linux/macOS
# или venv\Scripts\activate на Windows
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Настройка переменных окружения
Скопируйте файл `.env.example` в `.env`:
```bash
cp .env.example .env
```

### 4. Применение миграций базы данных
```bash
python manage.py migrate
```

### 5. Загрузка демонстрационных данных (рекомендуется)
Для быстрой проверки проекта запустите встроенную команду заполнения:
```bash
python manage.py seed_demo
```
Команда автоматически создаст:
- **Главного администратора**: логин `admin`, пароль `admin123`
- **Подтвержденного педагога**: логин `teacher_mikhail`, пароль `teacher123`
- **Педагога, ожидающего подтверждения**: логин `teacher_anna`, пароль `teacher123`
- **2 учебных курса**: «Основы Python для начинающих» и «Робототехника и микроконтроллеры Arduino» с модулями и подробными Markdown-уроками с видео.

### 6. Запуск сервера разработки
```bash
python manage.py runserver
```
Сервер будет доступен по адресу: [http://127.0.0.1:8000/](http://127.0.0.1:8000/)

## 👤 Управление пользователями и правами

### Роли в системе:
1. **Ученики (гости)**: доступ к публичной главной странице `/`, каталогу `/materials/`, детальным страницам курсов и уроков. Регистрация не требуется.
2. **Педагоги**:
   - Регистрируются по адресу `/accounts/register/`.
   - При регистрации создается аккаунт с `role='teacher'` и `is_approved=False`.
   - До момента подтверждения администратором педагог видит страницу ожидания `/accounts/pending/` и не имеет доступа к созданию материалов.
   - После подтверждения получает доступ к `/editor/`, где создает и редактирует **только свои материалы**.
3. **Администратор**:
   - Имеет полный доступ ко всем материалам всех педагогов в `/editor/`.
   - Имеет эксклюзивный доступ к редактированию настроек сайта `/settings/`.
   - Имеет доступ к списку пользователей `/settings/users/`.

### Создание нового администратора вручную:
```bash
python manage.py createsuperuser
```
Суперпользователи автоматически наделяются ролью `admin` и статусом `is_approved=True`.

### Как подтвердить аккаунт педагога:
1. Войдите в систему под учетной записью администратора (например, `admin` / `admin123`).
2. Перейдите в пункт верхнего меню **«Пользователи»** или откройте адрес `/settings/users/`.
3. В фильтре выберите вкладку **«Ожидают подтверждения»**.
4. Нажмите зеленую кнопку **«Подтвердить»** напротив нужного педагога.
5. Теперь педагог может полноценно войти в `/editor/` и создавать учебные материалы.

## 🗄️ Переключение на PostgreSQL (по желанию)
По умолчанию используется SQLite. Чтобы переключиться на PostgreSQL, достаточно указать строку подключения в файле `.env`:
```env
DATABASE_URL=postgres://username:password@localhost:5432/kvantlearn_db
```
и выполнить `python manage.py migrate`.
